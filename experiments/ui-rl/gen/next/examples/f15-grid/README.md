# 手工全部按网格的示例(f15)

`Page.tsx` 是第 1 遍观察 f15 v1(带经验清单)的页面,只改了两处:核心指标改成 9 列宽里 3 + 2 + 2 + 2(原来写的 `cols={12}` 不在栏线上),结论句行高 48px(`leading-12`,24 的倍数)。

`baseline.diff` 是在 `gen/next/report` 之上为了让每一行都落在 24px 基线上改的组件(还没并进 `gen/next/report`):

- 表格一行 48px,行线画在单元格里面(不再撑高行),文字贴在行线上方,单元格行高 24px;
- 编号列表每条上下各留一行,行线在条目底部(一行的条目共 72px);
- `Group` 标题和内容之间不再隔 8px,`Rule` 是一行 24px、线在底部;
- `Stat` 的数字行高 48px;
- 截图条里每张图占 2 列(172 × 360,原图按比例放进去、上对齐),图之间 24px,所以每张都从栏线开始;截图下的文字行高 24px。

量过:页面上每一段文字、每个表格单元格、指标、截图的左边都在栏线上(滚动条后面看不到的截图也按 98px 一列的节奏),上边都在 24px 基线上,每一节从场线开始。`shot.png` 是截图,`shot-grid.png` 画了网格(红:12 列;细蓝线:24px 基线;粗蓝线:场线,每 168px)。
