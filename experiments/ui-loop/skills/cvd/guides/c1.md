# 输出指南 · 色觉无障碍分析 c1(候选,基于 g0)

这份指南只管「色觉无障碍分析」这个 Skill 的输出:它的数据怎么用组件库呈现、页面怎么组装。通用做法在公共规范 design.md 里,这里不重复。和公共规范 B、C 部分冲突时,以本指南为准;A 部分(基础)不能改。

## 规则

- **G1 颜色表的列与位置**: `palette`、`confusions`、`contrast`、`fixes` 四张表放进同一节「色板与检查」,依次排成四张 `DataTable`(每张用 `caption` 写表名「配色」「混淆色」「对比度」「修复」),表与表之间 24px,中间不插别的块;这一节紧跟「模拟视图」一节之后,排在问题清单之前。凡单元格里出现颜色值的地方都写成「名称 色值」(如 `系列 2 #52C41A`),名称取 `palette` 里 `hex` 相同的 `name`,在 `palette` 里找不到的只写色值。`palette` 三列:名称(span 2)、色值(span 2)、用途(span 5)。`confusions` 七列:位置 `where`(span 2)、颜色对(span 2,`colors` 两个色值按上面的写法用「/」相连)、正常 `normal`(span 1,`align: "right"`)、红色盲(span 1,`align: "right"`)、绿色盲(span 1,`align: "right"`)、蓝色盲(span 1,`align: "right"`)、受影响 `affected`(span 1,用「、」拼),四个色差列里该行 `affected` 列出的类型的数值放进该列 `tone` 标红。`contrast` 六列:位置 `where`(span 3)、文字色 `fg`(span 1)、背景色 `bg`(span 1)、对比度 `ratio`(span 1,`align: "right"`)、要求 `required`(span 1,`align: "right"`)、结果(span 2,`pass` 为 false 的写「不达标」并放进该列 `tone`)。`fixes` 六列:位置 `where`(span 2)、原色 `from`(span 1)、建议色 `to`(span 1)、背景 `bg`(span 1)、修复前 `before`(span 2,`align: "right"`)、修复后 `after`(span 2,`align: "right"`)。
