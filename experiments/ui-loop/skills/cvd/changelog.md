## c1(审美 judge,基于 g0)· 成功 · 门禁采用

- 做法:让「核心指标」一节的几个 KPI 都用同一种大号数字,整组排在同一行、一行排满,不拆成两行、也不让最后一行只剩一个。
- 规则:G1(新增),针对 P-01
- 解决了:核心指标一节原本被拆成「一大三小」两行、右侧留下 L 形空白的地方,改后几个数字同字号、共基线、一行等宽排开,留白变规整(页面 c2)。
- 带出的问题:同一节几个 KPI 排满一行后彼此等权、横向拉得偏开,总括数字(问题总数)不再突出,读者一眼看不出主结论(页面 c2)。
- 门禁(验证页):程序检查问题 0 → 0 个;审美 judge(候选对当前版,3 轮):c5 赢赢平,c6 赢赢赢
- 教训:下次保留「KPI 整组一行排满、不拆行」这条,它确实能消掉 L 形空白;但要避开强行要求所有指标同一字号,以免把本来有主次设计的核心指标拉平,也别指望它管指标的先后顺序——一碰顺序,两种顺序的结论就打架(c1、c4)。
