# 问题清单 · 色觉无障碍分析

Maintainer 从训练样本的检测结果归纳,每步更新(最近一次:cvd-c10-k3,审美 judge)。Reviser 读「布局问题」,组件 Agent 读「组件不够」。改了什么、成没成功在修改记录 changelog.md(修改记录员写)。

## 组件不够

- **P-12**(审美 judge,2 页):色觉模拟要展示原界面与三种色觉模拟的四张对照图，但组件库缺少能把四张图在一屏内以可辨尺寸排成一组对照的组件，所以无法展示。
  - 赢的做法:四张对照图以能看清图内文字与色差的尺寸呈现，整组仍能在一屏内完成对照。
  - 证据:c2:两种顺序都提到——色觉模拟的四张缩略图过小，并被行距或分屏拆成两组/两屏，难以作为一组对照阅读。;c3:两种顺序都提到——色觉模拟区的 4 张图单张尺寸过大、连续占满屏幕，与其余区块的密度差距明显。;c2:四张模拟图缩得很小后，界面内的文字、进度条与按钮已小到不可辨，失去模拟对比的说服力。
- **P-15**(审美 judge,3 页):ProgressList 的条与轨道是近乎不可见的细线、且不带基线或刻度，使「按色觉类型的问题数」一栏的条形既看不出数值差异、也说不出这条线的作用。
  - 赢的做法:计数条与相邻表格共用对齐线，条上给出基线或刻度，数值差异一眼可辨。
  - 证据:c4:两种顺序都提到——问题分布条形是发丝级细线且没有基线/刻度，1 与 0 的长度差不可读，行内留白大。;c3:三条横线长度完全相同，不编码任何数值差异，像说不出作用的装饰；横线右端各自对齐到数字，与上方明细表不共列线。;c1:「按色盲类型」三行后面的横线长短不一、与右侧数字的距离也不一致，像输入框下划线，作用不明。
- **P-16**(审美 judge,1 页):DataTable 的数值条颜色过淡且不带阈值参考线，使「对比度明细」的对比度一列无法从条长判断是否达标。
  - 赢的做法:条形标出阈值参考线，长度与数值一起可读，行内不留不承载信息的空白。
  - 证据:c4:两种顺序都提到——对比度列数值后的条形没有 4.5 阈值参考线，颜色过淡、几乎看不见，读者无法从长度判断是否达标。;c4:数值与条形之间留出的大段空白没有承载信息，条形末端长短不齐使表格右缘显得毛糙。

## 布局问题

- **P-05**(审美 judge,2 页):「色觉模拟」一节的四张对照图与标签排布不成规整一组：标签与所属图片的间距过大、与图左边缘不对齐，留白不成矩形，读者无法把几张图当成同一组对照来读。
  - 赢的做法:四张对照图等宽排成规整一组，标签紧贴所属图片、与图左边缘对齐，留白成矩形，并与下方表格、图表共用同一条栏线。
  - 证据:c2:两种顺序都提到——色觉模拟第二屏/第二行的标签周围留白过多，标签与缩略图没有形成紧凑清楚的分组。;c1:标签与图的间距约 60px、已接近区块间距，标签归属不明确；四个标签居中排在图下，起点不与图表左边缘对齐。
- **P-11**(审美 judge,4 页):内容很少的节（结论、背景信息等）单独占一屏、页头与结论之间也留出近半屏空白，一屏里只有一两行内容、大半留白，读者会觉得报告没有写完。
  - 赢的做法:内容很少的节与前一个节合并，或压缩上下留白收尾，把结论上移、收紧标题区高度，使每屏都有两三种内容、模块间距仍是节内分组间距的两倍以上。
  - 证据:c4:两种顺序都提到——页面顶部标题与「结论」之间留白过多（接近半屏），首屏节奏不均衡，建议上移结论或压缩标题区高度。;c2:第 1 屏标题与结论之间约 600px 空白；色觉模拟第二屏只有两张小图加两个标签，大半是空白。;c3:结论、背景信息等屏只有一两行字，整页 section 间距普遍过大，留白明显偏多。;c1:第 1 屏只有标题加一段结论，上下各留大片空白，与相邻屏的密度落差大。
- **P-14**(审美 judge,2 页):「下一步/建议」一节的编号列表排成三列网格，条目数不是三的倍数时末行只剩一两项，右下留下 L 形空白，与全页规整的矩形留白不一致，读者会觉得这一块没收住。
  - 赢的做法:条目数与列数匹配（或改用单列、两列），末行不留孤立项和 L 形空白。
  - 证据:c4:两种顺序都提到——01–05 排在 3 列里，第二行只有 04、05 两项，右下空出整块 L 形空白。;c3:「下一步」区用三列网格排 01/02/03，第 04 项单独落到第二行第一列，右侧留下大片 L 形空白，是全页唯一明显脱线处。
- **P-17**(审美 judge,1 页):核心指标一节的四个同级指标里只有部分带红色注释、结论句又另起一层加粗大字，同类内容的强调方式不一致，读者分不清哪些信息同等重要。
  - 赢的做法:四个同级指标共用同一套数字与说明样式，不单独给部分指标加红色注释；结论句与其余正文保持同一套样式。
  - 证据:c2:两种顺序都判当前版输——四个 KPI 中只有后两个带红色小字注释（低于 4.5:1、绿色盲下 ΔE 9.0），另两个没有，同类指标的强调不完全一致。;c2:结论区用「加粗大字 + 小灰字」两段，与其余正文样式不同，全页多出一层额外强调。

## 已解决

- **P-01**(审美 judge):核心指标一节的四个同级指标被排成一行三项、第二行一项，右侧留下大片空白，读者看不出这四个数字属于同一组。
- **P-02**(审美 judge):颜色混淆一节的柱状图用多种高饱和色区分系列，填色面积最大的一根柱子承载的却是次要数据，抢走全页注意力，也和其余部分克制的灰加单一强调色配色冲突。
- **P-03**(审美 judge):明细一节把多张表格放进同一个区块、表与表之间的距离接近表内行距，读者会把它们当成一张长表，分不清是几组内容。
- **P-04**(审美 judge):核心指标一节的几个指标数字完全等权，结论性的总括数字没有比其余指标更突出，读者一眼看不出该先读哪个、抓不到主结论；指标之间间距偏大，也削弱了它们同属一组的关联感。
- **P-06**(审美 judge):ProgressList 的进度条为黑色粗条，使「按色盲类型」一栏的问题数条形视觉重量远高于页面其它元素，与全页细线风格不一致。
- **P-07**(审美 judge):核心指标一行的数字层级没有拉开：总结性指标与其余指标同字号同字重，只能靠位置区分重要程度，数字与单位的字号、基线关系也不统一，读者一眼抓不到主结论、单位也难读。
- **P-08**(审美 judge):「色觉模拟」一节把说明文字、多张对照截图和底部图注挤在同一屏内，模块间距小于节间距，是全页最挤的一屏，读者看不出哪几块属于同一组对照。
- **P-09**(审美 judge):DataTable 的 caption 固定居中，使各表格下方的口径注释落不到表格左右边缘上，表格右侧留出一块不规整的空白。
- **P-10**(审美 judge):FigureStrip 的滚动条一直显示，使色觉模拟的截图组下方多出一条贯通整栏的灰色横条，读者会把它当成多余装饰或分隔线。
- **P-13**(审美 judge):判定结果、严重度与色差阈值数值等多处同时用红色强调，同一强调色承担太多重点，单处的强调力被稀释，读者分不出哪一处才是最该先看的结论。
