# 修改记录

Recorder 写的。Reviser 每一步先读;效果:同一组里照这条经验做的页面和没照做的页面,平均分谁高(两边各至少 3 版才下结论,差 1 分以上算有效或失败)。

## 当前经验清单

- **E1** 核心指标四项一行排满、副行同有同无，结论数字首位放大、样本量与背景口径后置  
  依据 S1、S8;效果:数据不够(照做 10 版、没照做 2 版)
- **E2** 下一步建议用单列纵向编号排，依据内联在每条建议内，避免多列掉行  
  依据 S2;效果:数据不够(照做 0 版、没照做 0 版)
- **E3** 问题表把产品与步骤分列，不要合并成一格「位置」  
  依据 F2;效果:数据不够(照做 0 版、没照做 0 版)
- **E4** 不要对同一组数字用 KPI、大数字卡、横条图重复表达，同一强调层级只用一次  
  依据 F4;效果:有效(照做 8 版平均 0.6,没照做 10 版平均 -0.5)
- **E5** 问题表保留唯一编号列，下一步建议的依据写编号对回具体条目  
  依据 S7;效果:数据不够(照做 0 版、没照做 0 版)
- **E6** 当步骤有备注时，备注在链路卡内独起一行加标签，与步骤说明分两级间距  
  依据 S3;效果:数据不够(照做 0 版、没照做 0 版)
- **E7** 任务、范围、日期等元信息只在页尾背景信息出现一次，页头不重复  
  依据 S5;效果:数据不够(照做 0 版、没照做 0 版)
- **E8** 当产品数为 2 时，链路前用并排对比表列步骤数、输入项与结论，不散进副标  
  依据 S10;效果:数据不够(照做 0 版、没照做 0 版)

## 每处改动

- 第 2 步(f7)新增 E1:「四项核心指标一行排满，结论数字放大前置，样本量后置，避免末项掉行」;依据 S1;S1 在 f1、f7 多版验证：KPI 四项一行且首项数字放大得分高，掉行则失分
- 第 4 步(f10)新增 E2:「下一步建议用单列纵向编号排，依据内联在每条建议内，避免多列掉行」;依据 S2;两份报告数据中纵向单列建议列表均排满一致，多列网格会出现行不满、对齐线断掉。
- 第 4 步(f10)新增 E3:「问题表把产品与步骤分列，不要合并成一格「位置」」;依据 F2;两份报告数据中把产品与步骤并成一列导致对象归属难辨、需回头对照，分列后一眼可辨。
- 第 5 步(f9)新增 E4:「不要对同一组数字用 KPI、大数字卡、横条图重复表达，同一强调层级只用一次」;依据 F4;F4 是新模式，清单里没有关于避免同级强调重复、同一数据多形式重复表达的经验
- 第 6 步(f4)修改 E1:「四项核心指标一行排满，结论数字放大前置，样本量后置，避免末项掉行」→「核心指标四项一行排满，结构统一(副行同有同无)，数字放大前置，样本量后置」;依据 S1、S8;S8 补充了同一组 KPI 副行/注脚须同有同无、不留空，使 E1 的一行排满更完整
- 第 6 步(f4)新增 E5:「问题表保留唯一编号列，下一步建议的依据写编号对回具体条目」;依据 S7;清单未涉及问题编号与建议依据的锚点对应，S7 在两份数据里均带来高分
- 第 7 步(f8)修改 E1:「核心指标四项一行排满，结构统一(副行同有同无)，数字放大前置，样本量后置」→「核心指标四项一行排满、副行同有同无，结论数字首位放大、样本量与背景口径后置」;依据 S1、S8;S1 补充了四项内部的排序依据：结论性数字打头、规模口径后移，S8 补充副行同有同无，合并进原条更准确
- 第 8 步(f2)新增 E6:「当步骤有备注时，备注在链路卡内独起一行加标签，与步骤说明分两级间距」;依据 S3;清单无备注排版经验，两份数据都显示备注独行加标签更易分类。
- 第 8 步(f2)新增 E7:「任务、范围、日期等元信息只在页尾背景信息出现一次，页头不重复」;依据 S5;清单未涉及元信息位置，数据中重复或混入结论的版本均被扣分。
- 第 8 步(f2)新增 E8:「当产品数为 2 时，链路前用并排对比表列步骤数、输入项与结论，不散进副标」;依据 S10;清单缺产品级横向对照的做法，删表或拆散信息的版本被判难横向比较。
