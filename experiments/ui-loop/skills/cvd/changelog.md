## c1(审美 judge,基于 g0)· 成功 · 门禁采用

- 做法:让「核心指标」一节的几个 KPI 都用同一种大号数字,整组排在同一行、一行排满,不拆成两行、也不让最后一行只剩一个。
- 规则:G1(新增),针对 P-01
- 解决了:核心指标一节原本被拆成「一大三小」两行、右侧留下 L 形空白的地方,改后几个数字同字号、共基线、一行等宽排开,留白变规整(页面 c2)。
- 带出的问题:同一节几个 KPI 排满一行后彼此等权、横向拉得偏开,总括数字(问题总数)不再突出,读者一眼看不出主结论(页面 c2)。
- 门禁(验证页):程序检查问题 0 → 0 个;审美 judge(候选对当前版,3 轮):c5 赢赢平,c6 赢赢赢
- 教训:下次保留「KPI 整组一行排满、不拆行」这条,它确实能消掉 L 形空白;但要避开强行要求所有指标同一字号,以免把本来有主次设计的核心指标拉平,也别指望它管指标的先后顺序——一碰顺序,两种顺序的结论就打架(c1、c4)。

## c2(审美 judge,基于 g1)· 失败 · 门禁未采用

- 做法:让核心指标那一行里只有「问题总数」这个总括数字用大号字、另外三个保持普通字号,四个数字底边对齐,并且四个指标按数据原来的先后顺序摆、不重新排序。
- 规则:G1(改写),针对 P-04
- 解决了:两种顺序都没看到改善:核心指标一行里该先读哪个数字,改前改后一样看不出来。
- 带出的问题:核心指标一节:改成按原顺序摆之后,总括数字「问题总数」排到了一行最后,两处红色告警指标被中间的指标隔开,两种顺序都说这一行的阅读顺序和分组比改前乱。
- 门禁(验证页):程序检查问题 0 → 0 个;审美 judge(候选对当前版,3 轮):c5 平赢平,c6 输平输。没采用:审美 judge在验证样本上输了 1 份
- 教训:下次别只靠给单个指标换字号来突出结论数字——多数页面上两版看不出差别,还会牵动同一行数字与左栏标题的基线;也别把总括数字钉死在原始顺序上,两种顺序都确认那会把它压到末尾、打乱分组。

## c3(审美 judge,基于 g1)· 成功 · 门禁未采用

- 做法:把「核心指标」一节里代表问题总数的那个结论数字挪到整组最前面,其余指标按原来顺序跟在后面。
- 规则:G1(改写),针对 P-04
- 解决了:「核心指标」一节里最重要的「问题总数」原来排在整组末尾、落在最弱的位置,现在排到第一个,读者先读到结论再看分解,三张训练页、两种顺序都判改动后更好。
- 带出的问题:没有带出新的明显问题;只是四个指标仍同字号同字重,主次仅靠先后位置体现,「核心指标」一节数字缺少视觉层级、个别页 KPI 说明行多一行导致基线不齐,这些仍留在剩余问题里。
- 门禁(验证页):程序检查问题 0 → 0 个;审美 judge(候选对当前版,3 轮):c5 赢平赢,c6 输输输。没采用:审美 judge在验证样本上输了 1 份
- 教训:保留「把结论指标排到最前」这条;顺序只能表达主次、不能加重主次,单靠顺序(以及此前试过无效的换字号)都不足以让结论数字真正压过其余指标,下次要再强化主次得另找办法。

## c4(审美 judge,基于 g1)· 成功 · 门禁未采用

- 做法:把「核心指标」这一行的结论数字(问题总数)挪到最前面并加大字号,其余指标按数据原顺序跟在后面用普通字号,整组仍保持一行排满、不折行。
- 规则:G1(改写),针对 P-04
- 解决了:在「核心指标」一节,结论性的「问题总数」排到首位、字号更重,读者先读到总结论,阅读顺序和主次一眼可辨,与首屏判定一致(页面 c1、c4 两种顺序都判改动后更好)。
- 带出的问题:两种顺序都没有指出这次改动带出的新问题:「核心指标」之外的剩余问题(首屏留白偏多、区块间距过大、红色强调被稀释、各表右缘不齐等)改动前后完全相同,不是这次改动造成的。
- 门禁(验证页):程序检查问题 0 → 0 个;审美 judge(候选对当前版,3 轮):c5 赢赢平,c6 输平平。没采用:审美 judge在验证样本上输了 1 份
- 教训:下次改规则保留「结论指标排到核心指标行最前」这一手,它在能看出差别的页面上稳定改善阅读顺序;但要避开只给结论数字单独放大的做法——字号差异没有在两版共认中换来好处,还可能让本该同级的几个数字显得不成一组(有页面因此判改动前后各有胜负)。

## c5(审美 judge,基于 g1)· 成功 · 门禁未采用

- 做法:把核心指标组里表示问题总数的那一项提到整组第一位,其余指标保持数据里的原顺序,四项仍用同一套字号字重、不单独放大结论项。
- 规则:G1(改写),针对 P-04
- 解决了:核心指标一节:结论性的问题总数排到首位后,阅读顺序变成先总后分,与页首「结论」在前的结构一致,读者一眼知道先读哪一项,不再像三个分项后面突然跟一个合计。
- 带出的问题:没有带出新的问题;核心指标四个数字仍完全等权,总览项与分项只靠位置区分,数值相同的两个「6」仍可能看混(核心指标一节),这处是改动前就有的遗留,未因本次改动加重。
- 门禁(验证页):程序检查问题 0 → 0 个;审美 judge(候选对当前版,3 轮):c5 赢赢赢,c6 输输输。没采用:审美 judge在验证样本上输了 1 份
- 教训:保留「结论数字排整组最前、其余按原顺序、四项同一套数字样式」这一做法;不要再给结论项单独换字号或字重(已证无效),等权残留要另找不破坏同级一致性的办法。

## c6(审美 judge,基于 g1)· 成功 · 门禁采用

- 做法:把核心指标里的结论项「问题总数」挪到整组第一位，其余指标按原顺序跟在后面，四项仍用同一套样式、同一行同一条基线。

- 门禁(验证页):程序检查问题 0 → 0 个;审美 judge(候选对当前版,3 轮):c5 赢赢赢,c6 赢赢赢

## c7(审美 judge,基于 g2)· 失败 · 门禁未采用

- 做法:把「按色盲类型」这一组从带底轨的粗条改成表格:整组单独占「按色盲类型」一节,两列「色盲类型 / 受影响的问题数」,数字右对齐、后面接一根细条,问题数为 0 的类型也照常保留,列宽和同页明细表对齐。
- 规则:G2(新增),针对 P-06
- 解决了:「按色盲类型」单独成一节后,原来把它和柱状图、明细表挤在同一屏的页面,一屏的内容模块从 4 种降到 3 种、区块间距回到全页统一的节奏(c3 两种顺序都这么说)。
- 带出的问题:新表里表头「受影响的问题数」右对齐到表格最右,数值却落在表格中部,表头与自己的数据列不在同一条竖线上,条形起点和终点也不与同页表格的列线共用,该处留白成阶梯形或锯齿形(c1、c4 两种顺序都这么说)。;「按色盲类型」一节里的条形不再编码数值:三条等长、通栏的黑色实心条(0 值也照画等长轨道),读者读不出量级,还会把 0 误读成有数据,这一块同时成了全页最重的实心色块(c4 两种顺序都这么说)。;「按色盲类型」独立成一节后,在该节只有 3 行内容的页面上多出近半屏空白,和首屏、尾屏留白偏多的问题叠在一起(c1 两种顺序都这么说)。
- 门禁(验证页):程序检查问题 0 → 0 个;审美 judge(候选对当前版,3 轮):c5 平输输,c6 未改动。没采用:审美 judge在验证样本上输了 1 份

## c8(审美 judge,基于 g2)· 失败 · 门禁未采用

- 带出的问题:在 c1，「按色盲类型」单独成节后只有 3 条条形却占满一整节，「系列色」一节右半整块留空，两种顺序都说留白与分组比改前差。;在 c4，同一组计数被拆成独占一屏，只剩标题加三条横条、四周大半留白，还与同属「色差分析」的表格分了家，两种顺序都说不如改前。

## c9(审美 judge,基于 g2)· 失败 · 门禁未采用

- 做法:把「按色盲类型」的问题计数条从原来所在的区块挪进「明细」一节、排在问题明细表之前,改成与明细表同宽、共用同一条左对齐线的细条列表,每行是色盲类型、细条和数值,计数为 0 的类型也照常列出。
- 规则:G3(新增),针对 P-06
- 解决了:细条列表与问题明细表共用同一条左对齐线和列宽节奏,表格不再被旁边的条形列表挤窄、下方也不再留下 L 形空白(「明细」一节)。
- 带出的问题:细条并入后「明细」一屏同时出现细条、问题明细表、界面用色表等 4 种模块,超过一屏三种的上限,原本分散的模块被压在一起(「明细」一节)。;被抽走计数的原区块只剩一行表格、大半屏空白,留白反而更不均(「问题分布」一节)。;细条被拉成横贯整栏的粗黑长条,成为全页填色面积最大、视觉重量最重的一块,却只是重复表格里已有的计数(「问题清单」/「问题分布」一节)。;细条与其下表格的间距被压到低于全页的 section spacing,读者容易把条形误读成表格的一部分(「问题清单」一节)。;同一节里细条与表格的「类型」列重复表达同一份计数,且与「对比度明细」的比例条不是同一套长度尺度,同类组件出现两种样式(「问题清单」/「问题分布」一节)。
- 门禁(验证页):程序检查问题 0 → 0 个;审美 judge(候选对当前版,3 轮):c5 输平输,c6 输输输。没采用:审美 judge在验证样本上输了 2 份
- 教训:细条加行内数值、与明细表同宽对齐这条做法可以保留,但不要再把它塞进已经有表格的「明细」节、也不要拉成满宽粗黑长条,否则会挤爆一屏模块数、抽空原区块,并把视觉重量从内容本身抢走。

- 做法:把色觉模拟的四张对照图从一整条横排拆成每行两张(2×2),让每行都落在正文栏宽内。

## c11(审美 judge,基于 g3)· 没效果 · 门禁未采用

- 做法:把「色觉模拟」一节的四张对照图从「每行两张」改成同一条 FigureStrip 里一行排开,标签统一放到图下方,并让整组占满正文栏、左右边缘与同节表格图表的内容列对齐。
- 规则:G2(改写),针对 P-05
- 解决了:「色觉模拟」一节:对照图不再被拆成两行,两行之间近一整屏的行距和 L 形/锯齿形空白消失,图与标签成组、留白成规整矩形、右端落到同一条栏线上(c2、c3,两种顺序一致)。;「色觉模拟」一节:标签统一移到图下方后,四张图与四个标签一一对齐,同组内图与标签的上下关系一致(c2、c3,两种顺序一致)。
- 带出的问题:「色觉模拟」一节:四张并排后单图只剩内容栏约四分之一宽,图内文字与细节不可辨认,作为色觉模拟证据的可读性不足(c2、c3,两种顺序一致)。;「色觉模拟」一节:在原本两行就排得整齐的页面上(c1、c4),一行排开后图组变矮,该屏/区块下半留出大片空白,或四个面板挤进同一屏、单屏模块偏多,整体节奏反不如改动前(两种顺序一致)。
- 门禁(验证页):程序检查问题 0 → 0 个;审美 judge(候选对当前版,3 轮):c5 平赢输,c6 输赢输。没采用:审美 judge在验证样本上输了 1 份
- 教训:下次保留「标签贴在图下方、图组左右与表格内容列对齐」,别再用改「一行放几张」去消留白:四张挤一行会把单图压到不可读,一律拆成两行又会行距失控,应先保证单图可读宽度再定每行几张。
