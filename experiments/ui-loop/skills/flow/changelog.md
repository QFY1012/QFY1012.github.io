## c1(审美 judge,基于 g0)· 成功 · 门禁采用

- 做法:让核心指标节的 KPI 个数决定列宽:个数 ≤ 4 时排成一行、每项等宽占满整行,5–6 个时每行 3 个、末行按剩余个数等分排满,不再出现「3+1」的折行。
- 规则:G1(新增),针对 P-01
- 解决了:核心指标节:KPI 不再 3+1 折行,第 4 项不再孤立成行、右侧大片 L 形空白消失,几个指标排成规整一行(四页两种顺序都这么说)。;核心指标节:每项等宽后与下方表格等区块落在同一组列线和基线上,模块间留白成为规整矩形、网格对齐更干净(四页两种顺序都这么说)。;核心指标节:折行带出的那条介于区块内 gap 与 section spacing 之间的「第三级间距」消失,区块内/区块间两级节奏恢复(页面 f2、f4 两种顺序都这么说)。
- 带出的问题:无
- 门禁(验证页):程序检查问题 0 → 0 个;审美 judge(候选对当前版,3 轮):f5 赢赢赢,f6 赢赢赢
- 教训:保留:把「个数→列宽」写死、强制核心指标一行排满并与相邻区块共用列线的做法,四页上两种顺序都稳定判为更好;避开:别指望它顺手治折行以外的毛病(收尾屏大片空白、链路明细列数/行数不齐),那些要另开规则。

## c2(审美 judge,基于 g1)· 成功 · 门禁采用

- 做法:让链路明细里每个产品的截图各成一组、都从同一条左对齐线起排,组内按步骤依次放截图、步骤标签和说明;每步的补充备注从截图下方挪走,截图说明一律压成一行,使各组截图下方的文字行数一致、底边齐平。
- 规则:G2(新增),针对 P-02、P-04
- 解决了:链路明细各产品组截图下方的说明被压成固定行数,同一排说明块底边落在同一条线上,栏底不再参差。;每个产品组从同一条左对齐线起排、组内与组间间距分出两级,哪些步骤属于同一组一眼就能看出。;逐屏补充备注从截图说明里移出、统一收进「步骤备注」一节的列表或表格,同类内容形式一致、字号层级少一级。
- 带出的问题:新加的「步骤备注」一节与链路明细的间距两头不讨好:f1 里隔得太远、只能靠文字来回对照,f2、f4 里又挤在同一屏、间距不到一个区块,f3 里该节自身空掉半屏。;「步骤备注」表与原有「问题」表同页并存后关系不清(f2):一种顺序说两表样式完全相同、主次不分,另一种说列宽不同、表头不落同一条对齐线,同一页出现两套表格网格。
- 门禁(验证页):程序检查问题 0 → 0 个;审美 judge(候选对当前版,3 轮):f5 赢平赢,f6 平赢赢
- 教训:保留把链路明细每组截图的对齐线、图高和说明行数写死、并把补充备注从截图说明里移出统一收成固定形式的列表;避开只把备注挪走却不安排它相对链路明细的间距、以及它与页内既有表格的列宽和表头对齐线。
