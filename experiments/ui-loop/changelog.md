## v0 (初版,手写)  结果:采用

来源:用户从此前所有示例页面中选定目标风格,取 A/B 实验报告(`ab-f`)和体验走查报告(`review.clean`),两者在用户排序中都是第一名。规范按这两页的 spec 整理。

两页不一致处的取舍:
- 节间距:`ab-f` 96px,`review.clean` 192px,取 192px(用户最看重留白)。
- 结论句:`ab-f` 24px 细体,`review.clean` 20px,取 24px 细体(和 48px 细体大数字一致)。

两页都没有、按同一风格补写、尚未经用户排序验证的规则:B10 发现、B11 风险、C6 多个 Skill 拼成一页。
