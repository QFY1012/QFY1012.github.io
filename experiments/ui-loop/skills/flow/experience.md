# 问题清单 · 交互流程挖掘

Maintainer 从训练样本的检测结果归纳,每步更新(最近一次:flow-c10-k3-k4-k6,审美 judge)。Reviser 读「布局问题」,组件 Agent 读「组件不够」。改了什么、成没成功在修改记录 changelog.md(修改记录员写)。

## 组件不够

- **P-15**(审美 judge,1 页):DataTable 的 bar 细条颜色过淡、粗细与表格行线相同,使产品对比的步骤数列看不出数量差别,像一条说不出作用的装饰线。
  - 证据:f2:产品对比表「步骤数」列用无刻度横线表示步数，5 与 4 的长度差几乎读不出来，且与紧邻的数字重复，像误加的分隔线（两种顺序都提到）
- **P-21**(审美 judge,1 页):DataTable 的 tone 只提供一种红色标记，使问题明细表的严重度列只有「高」有颜色，中、低两级与正文没有视觉区别，读者读不出严重度的连续层级。
  - 证据:f2:问题表的「严重度」列只有「高」有颜色，「中」「低」与正文同色，三种状态表现不一致（两种顺序都提到）

## 布局问题

- **P-02**(审美 judge,3 页):链路明细里各产品一组的截图说明文字长短、行数不一，有的还被右边界截断，各组说明底部与截图行下缘参差不齐，读者看不出哪些步骤属于同一组。
  - 证据:f1:三家银行截图组下方的说明文字行数不一，三组截图块底部参差、下一组标题起始位置不齐;f1:远川银行组第 4 张截图的说明文字被右边缘截断;f4:链工 4 张截图下方的说明文字第 4 步折成两行，与前三列单行说明不等高，截图组底部留白参差
- **P-04**(审美 judge,2 页):链路明细里截图、说明与下一组之间的纵向间距不统一，说明紧贴截图、组与组之间又隔得太近，分组层级看不出来，读者分不清哪些内容属于同一组。
  - 证据:f3:链路明细截图与其下方内容之间的垂直间距不足，截图组的分组偏弱;f2:链路明细小橙组截图与下方「步骤备注」标题之间间距明显小于其它区块的 section spacing，使步骤备注看起来像小橙组的附属内容
- **P-05**(审美 judge,4 页):页面开头(标题与背景信息)和结尾(下一步)各有一屏只放两三行内容，其余大片留白，单屏信息密度过低，读者会觉得节奏松散。
  - 赢的做法:把背景信息紧接页头、与标题同组并以「下一步」收尾，同时把结论与核心指标、核心指标与流程对比并到同一屏，每屏内容模块数控制在 2 个左右，半空白屏更少、留白分布更均匀。
  - 证据:f1:问题明细、步骤备注后半、下一步几屏内容只占上半屏，下半屏整块空白;f2:首屏与末屏各留出接近半页空白，信息量过少;f3:末屏「下一步」只有两个编号项，下方约半屏空白，收尾明显偏空且与上一区块间距不成比例
- **P-06**(审美 judge,3 页):报告里数字的强调层级不统一:同一组数字里有的明显大于其它数字,同一批数据又在不同区块用不同强度的数字重复强调,读者分不清哪一组数字才是全页重点。
  - 赢的做法:把大数字强调只留给核心指标一处、同一组数字保持同一字号,其它对比改用正文级表格数字。
  - 证据:f1:核心指标与产品对比重复放大同一数字，两处 emphasis 互相削弱;f3:核心指标中「3 步」单独加粗放大，与其余三个同类 KPI 不一致;f4:流程概览 8 步/5 步 用大号数字，与上方核心指标的大号数字重复
- **P-08**(审美 judge,1 页):步骤备注这类条目少的分组排不满:条目分两列排后末行只占左列,右下方留下大块不成矩形的空白,这一节显得没收口。
  - 赢的做法:把条目少的分组改成通栏表格或单列排布,区块底边成矩形、不留半屏空白。
  - 证据:f3:步骤备注两栏列表第 3 行只剩 05 一项，右侧整块空出形成 L 形留白;f3:5 条短备注独占一整节，条目间距偏大，这一节显得没收口
- **P-09**(审美 judge,3 页):区块之间的纵向间距不统一:标题与紧随其后的第一块内容之间常常接近半屏或三分之一屏,同一页里有的区块又挨得过近,全页垂直韵律忽紧忽松。
  - 证据:f1:section spacing 约 90–120px，明显大于其余间距，页面被拉长、节奏松散;f2:链路明细小橙组截图与下方「步骤备注」标题之间间距明显小于其它区块的 section spacing，分组被削弱;f4:发现表格下方总结句与表格间距过小，容易被读成表格的一部分
- **P-12**(审美 judge,3 页):同一份报告里同类内容用了不同的组件形式:同为逐条记录,有的用编号列表、有的用表格,列表有的带分隔线有的没有,读者分不清条目边界,也不易判断哪些内容属于同一类。
  - 赢的做法:同类清单统一为「编号 + 加粗标题 + 灰色说明 + 分隔线」,同为横向对比的结构化数据统一用同款表格。
  - 证据:f1:「共性规律」与「下一步」同为编号列表却用了两套编号样式，层级感被削弱;f3:「步骤备注」与「下一步」两处都是短条目说明却一个用表格、一个用编号列表，同类内容组件不统一;f4:「每步备注」表把产品、步骤、屏名合并进同一单元格，与全页其它表格一列一值的形式不一致
- **P-13**(审美 judge,3 页):「下一步」多条建议并排成几栏时各栏文字行数不同、末栏偏短,栏底参差不齐,下方留出 L 形空白,这一节显得没收口。
  - 证据:f1:「下一步」4 条建议排成 3 列 + 第二行 1 列，第二行右侧约 2/3 宽留白形成 L 形空白，边缘不落在栏线上;f4:「下一步」三列改进建议的说明文字长短差异大，第三列仅一行，右下留白明显多于左侧
- **P-14**(审美 judge,4 页):报告里各区块的内容起始位置不在同一条栏线上:表格的左缩进、列表的编号列和数字列、同一区块里上下两块各自的列网格各自为政,全页出现多条互不对齐的竖线,读者会觉得每一节都没有对齐。
  - 赢的做法:所有区块左对齐到同一条栏线,表格列与截图各列都落在共同列线上,模块之间留白均为规整矩形。
  - 证据:f1:核心指标四个数字列距不均，与下方产品对比的等距三列不在同一组栏线上;f2:步骤备注表与问题表列线不同，同一页存在两条内容起始线;f3:核心指标四列水平间距不均，四个数字没落在同一套等宽栏线上;f4:「下一步」三栏列宽/列间距不均，第 3 栏明显偏右，其间留白不成矩形
- **P-17**(审美 judge,4 页):报告里同一信息在相邻位置重复出现:建议条目的自带编号与列表序号并列,备注的步骤列与上方截图说明重复,表格里同一个产品名逐行重复,读者要读两遍同样的内容,也挤占了正文宽度。
  - 证据:f2:步骤备注表的产品列每行重复「快送 / 快送 / 快送」，同一信息在相邻行重复出现;f3:步骤备注表第一列「云盒·5.3」连续重复三行，视觉冗余;f4:「下一步」同时用 01/02/03 与 A1/A2/A3 双重编号，编号冗余
- **P-19**(审美 judge,3 页):报告里的表格列宽分配不合理:窄列里的内容被挤成多行、宽列之间留出大片空带,表格内部留白不成矩形,相邻表格的列线也互不重合。
  - 证据:f2:步骤备注表与问题表列线不同，两张表列宽比例不一致;f3:「问题」表的 P1 行「证据」列文字换行，使该行比 P2/P3 高约一行，行高不齐;f4:问题表「依据」列过窄，P2 行文字折成两行，该行明显比其它行高，严重度列右侧多出一块空白

## 已解决

- **P-01**(审美 judge):核心指标一节把数字按三列排，余下的数字单独折到第二行，右侧留出大片不成矩形的空白，几个指标不在同一视觉组里，读者会觉得这一节没排满、节奏被拉断。
- **P-03**(审美 judge):DataTable 的 caption 注释固定居中，使表格下方要与表格左边缘对齐的口径说明脱离表格左对齐线，像一条游离在表格之外的尾巴。
- **P-07**(审美 judge):每步备注被抽成独立的表或块放在截图组之后，与对应的截图之间没有编号或指向关联、又不在同一屏，读者要跨区块回看才能把备注和截图对上，内容还与截图说明重复。
- **P-10**(审美 judge):链路明细要在不同产品的截图组之间做出分组,但组件库缺少线宽与表格行线一致的分组标记组件,所以无法展示。
- **P-11**(审美 judge):报告里的表格在页边界被切开:表头不重复、注释单独落到下一屏,读者要跨屏拼接才能把列首和注释对上,也看不出注释属于哪张表。
- **P-16**(审美 judge):DataTable 的 tone 只改字色、不提供字重或标记,使问题明细表的严重度一列只有颜色一个通道,标红的值与普通文字没有粗细差别,色弱读者和灰度打印读不出轻重。
- **P-18**(审美 judge):步骤备注、发现这类逐条清单没有分出层级:同一产品的条目和其它产品一律等距排在一起,条目间距又和区块间距接近或过疏,读者看不出分组、也读不出节奏。
- **P-20**(审美 judge):并列的两张表格(产品对比与问题)用同一套表头与行线样式、没有分组线,读者分不出哪张是中性对比数据、哪张是问题清单。
