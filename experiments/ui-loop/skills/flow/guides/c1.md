# 输出指南 · 交互流程挖掘 c1(候选,基于 g0)

这份指南只管「交互流程挖掘」这个 Skill 的输出:它的数据怎么用组件库呈现、页面怎么组装。通用做法在公共规范 design.md 里,这里不重复。和公共规范 B、C 部分冲突时,以本指南为准;A 部分(基础)不能改。

## 规则

- **G1 链路明细**:明细一节里,按 `chains` 一款产品一组:`Group` 的 `title` 写 `${product} · ${version}`,组内放一个 `FigureStrip`,按 `no` 升序把该产品 `steps` 里的每一步放成一个 `Figure`,个数与 `steps` 长度一致,靠后的步骤留在同一行的滚动区里,不省略也不折成两行裁掉。每个 `Figure` 从上到下依次是 `FigureImage`(`src` 用 `step.image`,`alt` 写 `${product} 第 ${no} 步:${screen}`)、`FigureLabel`(写「第 ${no} 步 · ${screen}」)、`FigureText`(写 `${content} · ${action} · 输入 ${inputs} 项`,末尾再接 `note`,`note` 为空则省略)。每一步的备注和输入项数只写在这张图下面,不再另开表格;产品数、步骤数不同时做法不变,产品依次上下排开。
