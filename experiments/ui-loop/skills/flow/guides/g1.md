# 输出指南 · 交互流程挖掘 g1

这份指南只管「交互流程挖掘」这个 Skill 的输出:它的数据怎么用组件库呈现、页面怎么组装。通用做法在公共规范 design.md 里,这里不重复。和公共规范 B、C 部分冲突时,以本指南为准;A 部分(基础)不能改。

## 规则

- **G1 链路明细**:`chains` 单独一节(`Section` 的 title 用「链路明细」),每个产品一个 `Group`(`title` 写「产品 · 版本」),组按 `chains` 数组顺序上下排;组内按 `steps` 顺序排,每行一个 `FigureStrip`、最多放 3 步,超过 3 步的接着排下一行(仍在同一个 `Group` 里),每一步都要有图、不省略,整行在 9 列内放得下、不出现横向滚动;每张图的 `FigureLabel` 写「第 N 步 · 屏名」,`FigureText` 写「内容 · 操作 · 输入 K 项」,该步在 `issues` 里有记录时(问题的 `product` 等于该产品或为「全部」,且 `step` 等于该步的 `no`)在标签末尾加「 · 问题编号」(如「第 2 步 · 分享设置 · P1」,命中多条时用顿号隔开)。
