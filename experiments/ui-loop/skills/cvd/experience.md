# 问题清单 · 色觉无障碍分析

Maintainer 从训练样本的检测结果归纳,每步更新(最近一次:cvd-c10-k3-k4-k6-k7,审美 judge)。Reviser 读「布局问题」,组件 Agent 读「组件不够」。改了什么、成没成功在修改记录 changelog.md(修改记录员写)。

## 组件不够

- **P-02**(审美 judge,1 页):BarChart 的多系列默认配色用色多、饱和度高，使颜色混淆一节的柱状图成为全页视觉重量最大的一块，抢走结论的注意力。
  - 赢的做法:同一组数据改用中性灰阶或低饱和呈现、只留一个强调色，红色只留给判定结果，全页视觉重量回到最重要的内容上。
  - 证据:c3:颜色混淆区的柱状图用橙、青、深蓝、黄四种高饱和色，是全页面积最大的实心色块，承载的却是次要的说明数据，与全页黑灰细线加单点红的克制配色冲突。;c3:该图 accent 超过两种且饱和度不一致，抢走了结论与问题清单的焦点。
- **P-12**(审美 judge,3 页):FigureCompare 的每格图高固定、图注又各占一行，使截图比例偏长的报告里四张对照图仍被拉成上下两屏，后一屏只剩两张图与两个图注，读者无法在一屏内完成对照。
  - 赢的做法:四张对照图以能看清图内文字与色差的尺寸呈现，整组仍能在一屏内完成对照。
  - 证据:c2:色觉模拟区块两张模拟图与前两张分屏，该屏只剩「绿色盲 / 蓝色盲」两个小标签，几乎全空，四张图被拉成两屏、无法作为一组对照阅读。;c3:色觉模拟区连续几屏每屏只有两张图，图被缩得过小、图内标签与色块细节几乎不可读，而该区块上下留白又很大，可用空间没用在信息上。;c4:色觉模拟四张模拟视图缩得过小，图内标签与色块细节几乎不可读，上下留白却很大。
- **P-15**(审美 judge,2 页):ProgressList 的条是发丝细线或等长虚线、不带基线或刻度，条目标签还带多种颜色，使「按色觉类型的问题数」一栏既看不出数值差异、说不出这条线的作用，也与页面其它数字的呈现方式不一致。
  - 赢的做法:计数条与相邻表格共用对齐线，条上给出基线或刻度，数值差异一眼可辨，并与页面其它数字用同一套呈现。
  - 证据:c3:受影响问题数的三条横线长度相同、无刻度，只能读右侧数字，条形本身不承载信息，属可删的装饰；同一计数在别处用表格数字表达，同类计数用了两种形式。;c4:问题分布 · 按色觉类型的三条横线长度几乎相同（1、1、0），线长读不出数量差异；条形线细长、数值与条形之间距离过大，与上方标题间距不统一，视觉上稀疏不成组。
- **P-24**(审美 judge,1 页):Section 的节标题相对内容垂直居中，使同一页里各节的标题有的顶对齐、有的居中，读者对不齐各节的起始线、看不出内容的分组。
  - 赢的做法:各节的标题都顶对齐到内容首行，全页左栏与内容栏的起线一致。
  - 证据:c1:「色觉模拟」的标题相对整块 2×2 图垂直居中，与上下「结论 / 混淆色 / 对比度」等顶对齐的标签不在同一水平线上。;c1:同一页里区块标签有的居中有的顶对齐，左栏与内容栏的起线不统一。

## 布局问题

- **P-03**(审美 judge,2 页):同一节里把多种内容模块排在同一屏、模块间距小于节内分组间距，读者会把它们混成一块、分不清这一节里有几种内容。
  - 赢的做法:每块内容分到各自分组、组间距按节级处理，或把块标题层级做重，使分界一眼可见。
  - 证据:c3:颜色混淆一节把柱状图（含图例）、明细表、受影响问题数条形列表三块挤在同一屏，密度明显高于其余各屏；结论区块里正文与背景信息也挤在同一区块，只隔一个行距级别。;c4:色差分析屏内 ΔE 表与问题分布条形图只隔约 1.5 个行高，与节间距接近，层级被拉平；问题清单表与色板 token 表之间只隔 1.5–2 个行高，分组感被削弱。
- **P-05**(审美 judge,1 页):「色觉模拟」一节的四张对照图与标签排布不成规整一组：图注与所属图片的间距和与相邻一排图的间距接近、归属不清，留白不成矩形，读者无法把几张图当成同一组对照来读。
  - 赢的做法:四张对照图等宽排成规整一组，标签紧贴所属图片、与图左边缘对齐，留白成矩形，并与下方表格、图表共用同一条栏线。
  - 证据:c1:2×2 图组的 caption 与上方图表、下方第二排图表的间距接近，归属不清，容易被读成下一排图的标题；建议把 caption 贴近其所属图（上距明显小于下距）。;c1:标签与看板的间距和图表内部间距接近，分组层级不够明显。
- **P-11**(审美 judge,3 页):内容很少的节（结论、背景信息等）单独占一屏、页头与结论之间也留出近半屏空白，一屏里只有一两行内容、大半留白，读者会觉得报告没有写完。
  - 赢的做法:内容很少的节与前一个节合并或就近成组，或压缩上下留白收尾，把结论上移、收紧标题区高度，使每屏都有两三种内容、模块间距仍是节内分组间距的两倍以上。
  - 证据:c1:两种顺序都提到的剩余问题——页面存在大片空白、区块间距或密度不当，整体视觉过轻、偏松散；section spacing 约 120–240px，多屏下半部大片空白。;c2:首屏标题到结论间距约 230px，上下空白合计超过屏高 3/4；「颜色混淆」+「问题分型」一屏两张短表合计不到 10 行；「背景信息」一屏仅 5 行，是全页最空的一屏。;c4:首屏（标题 + 结论）、色觉模拟页四张图下方、下一步条目下方都有半屏以上空白；核心指标与色觉模拟之间约半屏空白。
- **P-13**(审美 judge,3 页):判定结果、严重度与色差阈值数值等多处同时用红色强调，同一强调色承担太多重点，单处的强调力被稀释，读者分不出哪一处才是最该先看的结论。
  - 赢的做法:红色只留给判定结果（不达标、严重度高），阈值和色差数值改用中性色加粗，让红色在全页只有一个含义。
  - 证据:c1:红色强调点十余处——混淆色 5 个红粗数字、对比度 6 处「不达标」红字、问题表 3 处「高」红字，互相稀释；对比度表另新增 7 处红色「不达标」，强调层级被摊薄。;c2:KPI 数字下多了两处红色小注（低于 4.5:1、绿色盲下 ΔE 9.0），加上表内红字共 4 处以上，红色散布在多处、单点强调被稀释。;c4:ΔE 表中 0.3、5.9、8.2 三个红数值，加上「不达标」「高」与对比度明细里的数值横条，强调点比对照版分散。
- **P-14**(审美 judge,3 页):「下一步/建议」一类的条目排成固定列数的网格时，条目数不是列数的倍数、或条目文案换行，末行只剩一两项或行高不齐，右下留下 L 形或锯齿状空白，读者会觉得这一块没收住。
  - 赢的做法:条目数与列数匹配（或改用单列、两列、等宽 2×3 排布），文案压到一行，末行不留孤立项和 L 形空白。
  - 证据:c1:「下一步 · 问题的改法」六条三列网格中第三条与第六条的说明文字换行到两行，列高不齐，底部出现参差的 L 形空白。;c3:「下一步」01/02/03 排成一行、04 单独落到第二行左列，右下方留下不成矩形的空白，网格不完整。;c4:「下一步」3 列编号网格第二行只剩 04、05 两项，右下角留出一大块 L 形空白，且与页内其他列表/表格的排列语言不同。
- **P-17**(审美 judge,1 页):核心指标一节的四个同级指标里只有部分带红色注释、结论句又另起一层加粗大字，同类内容的强调方式不一致，读者分不清哪些信息同等重要。
  - 赢的做法:四个同级指标共用同一套数字与说明样式，不单独给部分指标加红色注释；结论句与其余正文保持同一套样式。
  - 证据:c2:同一组四个核心指标中只有「对比度不达标」「色盲难以区分」两项下面多了红色补充行，另两项没有，同类内容内部结构不一致。;c2:「低于 4.5:1」「绿色盲下 ΔE 9.0」两行红字紧贴 KPI 标签，与标签争层级，同时使全页红色强调点增至 4 处以上。
- **P-19**(审美 judge,3 页):表格、键值行与计数列表的数字右边缘落在不同的线上，并排各栏的栏线也不跨节贯通，右侧留白不成矩形、出现 L 形或锯齿状空白，读者看不出这些内容属于同一套列。
  - 赢的做法:各表格、数值列表与键值行共用同一组栏线，数值列右边缘对齐，并排各栏与相邻节的栏线贯通，留白都是规整矩形。
  - 证据:c1:「系列色」一节三栏并置，第三栏与上方图表第二栏不共线，纵向栏线不贯通。;c2:明细区三张表列数不同（6 列 / 5 列 / 3 列），列线互不对齐，表与表之间只留窄缝，形成 L 形与锯齿状空白。;c3:色觉模拟图组每行两张、右边缘只到版心中部，与下方跨到更右的表格不在同一对齐线上，图组右侧留下大块不成矩形的空白。
- **P-20**(审美 judge,2 页):结论区里判定句、结论句与补充说明用几乎相同的字号和字重，读者分不清哪一句是结论、哪一句是补充。
  - 赢的做法:结论句用结论字号单独成句，补充说明退回正文样式，两层一眼可分。
  - 证据:c2:结论区两段文字主结论与第二段补充文字字号接近、内容重叠，视觉上分不出主次；同一层「结论正文」被拆成一大一小两级。;c3:「判定:不友好」与正文同字号、同颜色、同粗细混在一段里，全页最重要的结论没有层级，读不出这是判断结果。
- **P-22**(审美 judge,1 页):色板一节里计数条图与相邻色值表并排时高度差大，条图下方空出不成矩形的留白，读者看不出这两块属于同一行。
  - 赢的做法:并排两块的高度与行节奏匹配，或把条目少的块改为通栏、并入相邻表格，不留不成矩形的空白。
  - 证据:c1:「系列色」区块左栏表格 8 行、右栏条形列表仅 3 行，右栏下方留下大片 L 形空白，两块高低不齐。;c1:「类型分布」一节只有三行细横条占据左侧一小块，右侧与下方是大片空白，整节视觉过轻、与上下区块的密度不匹配。
- **P-23**(审美 judge,3 页):同一批内容在同一页里用两种形式各呈现一遍（明细表逐条列出后编号列表再列一遍、同一类状态既用红字又用标签、同一批问题用两套编号），读者分不清两处的关系、也无法把编号对应起来。
  - 赢的做法:同类内容在全页只保留一种呈现形式：问题只在明细里列一次、状态只用一种样式、编号沿用同一套，读者能一一对应。
  - 证据:c1:「问题」既在明细表中逐条列出，又在「下一步 · 按问题处理」里以 01–06 编号项重复呈现同一批发现，同一层内容出现表格与编号项两种形式。;c3:同一类「状态」信息用了两种形式——表格里是红字「不通过」，问题清单里是圆角标签「高 / 中」，形式不统一。;c4:「下一步」的 01–05 编号与「问题清单」的 P1–P5 编号是两套体系，同一批问题读者无法直接对应。

## 已解决

- **P-01**(审美 judge):核心指标一节的四个同级指标被排成一行三项、第二行一项，右侧留下大片空白，读者看不出这四个数字属于同一组。
- **P-04**(审美 judge):核心指标一节的几个指标数字完全等权，结论性的总括数字没有比其余指标更突出，读者一眼看不出该先读哪个、抓不到主结论；指标之间间距偏大，也削弱了它们同属一组的关联感。
- **P-06**(审美 judge):ProgressList 的条比页面其它细线粗，使「按色盲类型」一栏的计数条成为屏内视觉重量最大的一块，与全页细线风格不一致。
- **P-07**(审美 judge):核心指标一行的数字层级没有拉开：总结性指标与其余指标同字号同字重，只能靠位置区分重要程度，数字与单位的字号、基线关系也不统一，读者一眼抓不到主结论、单位也难读。
- **P-08**(审美 judge):「色觉模拟」一节把说明文字、多张对照截图和底部图注挤在同一屏内，模块间距小于节间距，是全页最挤的一屏，读者看不出哪几块属于同一组对照。
- **P-09**(审美 judge):DataTable 的 caption 固定居中，使各表格下方的口径注释落不到表格左右边缘上，表格右侧留出一块不规整的空白。
- **P-10**(审美 judge):FigureStrip 的滚动条一直显示，使色觉模拟的截图组下方多出一条贯通整栏的灰色横条，读者会把它当成多余装饰或分隔线。
- **P-16**(审美 judge):DataTable 的数值条颜色过淡且不带阈值参考线，使「对比度明细」的对比度一列无法从条长判断是否达标。
- **P-18**(审美 judge):核心指标一行的几个数字之间横向间距过大、接近节与节之间的间距，四个数字读起来不像一组，缺少比节更紧的绑定。
- **P-21**(审美 judge):Group 的子块标题与节标题同为 20px，使「下一步」等节里的「颜色调整」「按问题处理」这类子块标题与节标题分不出层级，读者看不出这一节分成几块。
