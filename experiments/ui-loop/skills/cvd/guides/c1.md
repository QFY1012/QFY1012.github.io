# 输出指南 · 色觉无障碍分析 c1(候选,基于 g0)

这份指南只管「色觉无障碍分析」这个 Skill 的输出:它的数据怎么用组件库呈现、页面怎么组装。通用做法在公共规范 design.md 里,这里不重复。和公共规范 B、C 部分冲突时,以本指南为准;A 部分(基础)不能改。

## 规则

- **G1 问题清单与整改对照**: 明细节用 `DataTable` 排 `issues`,一行一条问题,列依次为编号(`id`,span 1)、位置(`location`,span 2)、类型(`type`,span 1)、严重度(`severity`,span 1,`tone: ["高"]`)、影响(`affects`,span 2,值用「、」连接、空数组写「—」)、建议(`suggestion`,span 2),各列 span 之和为 9;行按严重度「高 → 中 → 低」排,同级保持数据原顺序。`fixes` 非空时在同一节里紧跟这张表再放一个 `DataTable`:位置(`where`,span 3)、修改前(`from`,span 2)、修改后(`to`,span 2)、对比度(把 `before` 和 `after` 写成「3.36 → 5.33」,span 2);`fixes` 为空或没有这个字段时整张表省略。下一步节用 `List` 并与问题清单共用同一套编号:一条对应 `issues` 里的一条,`title` 写「`id` · `title`」,`description` 写 `suggestion`,顺序与问题清单一致,不合并、不遗漏;问题 3 条及以下时 `columns={3}`,4 条及以上时 `columns={2}`,都不加 `numbered`/`ordered`。
