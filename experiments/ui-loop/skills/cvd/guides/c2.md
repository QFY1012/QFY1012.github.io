# 输出指南 · 色觉无障碍分析 c2(候选,基于 g0)

这份指南只管「色觉无障碍分析」这个 Skill 的输出:它的数据怎么用组件库呈现、页面怎么组装。通用做法在公共规范 design.md 里,这里不重复。和公共规范 B、C 部分冲突时,以本指南为准;A 部分(基础)不能改。

## 规则

- **G1 颜色表的内容与排布**:`palette`、`confusions`、`contrast`、`fixes` 四张表合并到同一节「色板与检查」,紧跟展示 `screens` 的「模拟视图」一节之后、排在展示 `issues` 的问题清单一节之前;这一节写成 `<Section className="gap-12">`,四张表按配色 → 混淆色 → 对比度 → 色值修正的顺序,每张表用一个 `Group` 包住一张 `DataTable`,表名写在 `Group` 的 `title` 里(显示在表格上方),组与组之间 48px;某个数组缺失或为空时对应的 `Group` 整块不渲染,四张表都为空时这一节不出现。凡单元格里出现颜色值都写成「名称 色值」(如 `系列 2 #52C41A`),名称取 `palette` 里 `hex` 相同的 `name`,在 `palette` 里找不到的只写色值;`palette` 表自己的色值列只写 `hex`,不再重复名称。各表列与 span(每张表各列 span 之和为 9):`palette`——名称 2、色值 2、用途 5;`confusions`——位置 `where` 2、颜色对 2(`colors` 两个色值按上面的写法用「/」相连)、正常 `normal` 1(右对齐)、红色盲 1(右对齐)、绿色盲 1(右对齐)、蓝色盲 1(右对齐)、受影响 `affected` 1(用「、」拼,空数组写「—」),四个色差列里属于该行 `affected` 的数值用该列的 `tone` 标红;`contrast`——位置 `where` 3、文字色 `fg` 1、背景色 `bg` 1、对比度 `ratio` 1(右对齐)、要求 `required` 1(右对齐)、结果 2(`pass` 为 false 写「不达标」并用该列的 `tone` 标红);`fixes`——位置 `where` 2、原色 `from` 1、修正色 `to` 1、背景 `bg` 1、修复前 `before` 2(右对齐)、修复后 `after` 2(右对齐)。
