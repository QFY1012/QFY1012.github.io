# 问题清单 · 色觉无障碍分析

Maintainer 从训练样本的检测结果归纳,每步更新(最近一次:cvd-c10,审美 judge)。Reviser 读「布局问题」,组件 Agent 读「组件不够」。改了什么、成没成功在修改记录 changelog.md(修改记录员写)。

## 组件不够

- **P-06**(审美 judge,3 页):ProgressList 的进度条为黑色粗条，使「按色盲类型」一栏的问题数条形视觉重量远高于页面其它元素，与全页细线风格不一致。
  - 赢的做法:小条形图组与相邻表格共用一条对齐线，并给出刻度或数值基准；条用与页面细线一致的细条、浅色条，不与正文争夺视觉重量。
  - 证据:c1:系列色表格右侧「按色盲类型」的黑色粗条视觉重量明显高于页面其它元素，承载的却只是计数信息，三条同为黑色、与红色盲/绿色盲/蓝色盲标签无颜色对应。;c3:受影响问题数条形图的黑色横条与灰轨道线粗细一致，是屏内视觉重量最大的一块。;c4:问题分布条形图只占内容列左侧约三分之一，右侧三分之二空着，该屏右下出现一大块空白。
- **P-09**(审美 judge,2 页):DataTable 的 caption 固定居中，使各表格下方的口径注释落不到表格左右边缘上，表格右侧留出一块不规整的空白。
  - 赢的做法:口径注释与表格左边缘对齐，或写进所在节/组的说明文字里，不在表尾留一条居中错位的注释行。
  - 证据:c1:混淆色表格下方关于 CIEDE2000 ΔE 的注释偏右居中，未落在表格列线或左对齐线上，破坏了网格对齐。;c2:各表格下方的居中说明小字右端不落在表格右边界上，与表格形成不规整的右侧留白。
- **P-10**(审美 judge,3 页):FigureStrip 的滚动条一直显示，使色觉模拟的截图组下方多出一条贯通整栏的灰色横条，读者会把它当成多余装饰或分隔线。
  - 赢的做法:图组下方不出现多余的横条；需要分隔时用与全页一致的细线或明确的组标题。
  - 证据:c1:色觉模拟各看板下方一条灰色粗条，看不出是状态指示还是装饰，作用不明确。;c2:色觉模拟图下方一条贯通全宽的浅灰分隔线，既不分隔表格行也不表示状态，近似多余装饰。;c3:模拟视图图组下方一条灰色横条，像残留滚动条，明显比表格/列表的细分割线粗。
- **P-12**(审美 judge,2 页):FigureImage 的固定高度，使色觉模拟的四张对照图并排后单图过窄，图内文字与状态细节无法辨认。
  - 赢的做法:对照图等宽铺满内容列宽（每行两张）、左右边缘与表格和图表对齐，并保证每张截图里的文字与状态细节可辨认。
  - 证据:c2:四张模拟图被压在一行，每张宽约 200px，界面内的文字、进度条与按钮已小到不可辨，失去模拟对比的说服力。;c3:四张地图一行并排后每张宽约 150px，路名文字和色块过小，四张图的色差需要凑近才能辨认，削弱了本页最核心的对比证据。

## 布局问题

- **P-02**(审美 judge,1 页):颜色混淆一节的柱状图用多种高饱和色区分系列，填色面积最大的一根柱子承载的却是次要数据，抢走全页注意力，也和其余部分克制的灰加单一强调色配色冲突。
  - 赢的做法:同一组数据改用中性灰阶细条加单一强调色呈现，红色只留给判定结果，全页视觉重量回到最重要的内容上。
  - 证据:c3:柱状图用橙、黄、青、深蓝四色加「不通过」红字，饱和度不一（黄最亮）；视觉重量最大的橙色大柱承载的是正常视觉数据、并非全页最重要的结论。;c3:建议把图表收敛为两种强调色加中性灰，红色只留给「不通过」。;c3:同类图表与明细表、受影响问题数同屏时，柱状图仍是屏内最重的一块。
- **P-03**(审美 judge,1 页):明细一节把多张表格放进同一个区块、表与表之间的距离接近表内行距，读者会把它们当成一张长表，分不清是几组内容。
  - 赢的做法:每张表分到各自分组、组间距按节级处理，或把每张表的标题层级做重，使分界一眼可见。
  - 证据:c2:明细一节把对比度检查、问题清单、界面用色三张表格连续堆在同一屏，表间只隔约 1.5–2 个正文行高，与表内行距的级差不够，分组偏弱。;c2:两种顺序都判当前版输——当前版同时存在明细三表同屏偏挤与模拟区过空两种毛病。;c2:建议加大表间间距，或把每张表的标题层级做重，让三块的分界一眼可见。
- **P-05**(审美 judge,4 页):「色觉模拟」一节的四张对照图排布不成规整一组：图占不满正文栏、右端落不到同一条栏线上，或标签与图错位、留白不成矩形，读者无法把几张图当成同一组对照来读。
  - 赢的做法:四张对照图等宽排布、左右边缘与下方表格和图表的内容列对齐，标签紧贴图片，留白成规整矩形、整页少一屏；单图偏小的问题另行解决。
  - 证据:c1:两种顺序都提到色觉模拟区四张模拟图的排布与标签间距处理不佳，留白过多、分组层级不清。;c2:两种顺序都判当前版输——四张模拟图改成 2×2 后标签与图片错位，第二行只剩标签、留出大半屏空白，同一组组件出现两种图文关系。;c3:两种顺序都判当前版输——2×2 把模拟视图拉长约两屏，图组右边缘远短于表格与图表的右边缘，右侧留下大片非矩形空白。;c4:色觉模拟右侧面板宽度超出内容栏、被页面右边缘裁掉；两块面板之间又留下约 300px 无内容空档。
- **P-07**(审美 judge,1 页):核心指标一行的数字层级没有拉开：总结性指标与其余指标同字号同字重，只能靠位置区分重要程度，数字与单位的字号、基线关系也不统一，读者一眼抓不到主结论、单位也难读。
  - 赢的做法:结论性的总括数字排在核心指标首位，四个指标排在同一行、共用同一条基线与同一套数字/单位/标签样式，数字与单位的大小和基线关系一致。
  - 证据:c3:核心指标的 4 个 KPI 数字字号接近页面主标题、四个数字同等放大，主标题的层级优势被削弱、emphasis 被稀释，建议略收小数字或加大主标题与数字的对比。;c3:四个数字同等放大被列为额外 emphasis，略偏多。
- **P-08**(审美 judge,1 页):「色觉模拟」一节把说明文字、多张对照截图和底部图注挤在同一屏内，模块间距小于节间距，是全页最挤的一屏，读者看不出哪几块属于同一组对照。
  - 赢的做法:把「色觉模拟」的截图组拆到独立的一屏，或下移底部图注，使一屏内的内容模块不超过两三种、模块间距不小于节内分组间距。
  - 证据:c1:最挤的一屏是「色觉模拟」——节标题加四张看板截图，模块超过三种，标题与看板间距约 1 个正文行高。;c1:标签与看板的间距和图表内部间距接近，分组层级不够明显。
- **P-11**(审美 judge,4 页):内容很少的节（结论、背景信息等）单独占一屏，一屏里只有一两行内容、大半留白，读者会觉得报告没有写完。
  - 赢的做法:内容很少的节与前一个节合并，或压缩上下留白收尾，不让整屏只剩几行字。
  - 证据:c1:结论区块只有标题和一段正文，其余大半空白，与相邻屏的密度落差大。;c2:首屏标题与结论之间约 400px 空白，单屏只有标题加一段结论，偏空。;c4:末屏「背景信息」只有几行键值对，下方约三分之二为空白，页面收尾没有收住。
- **P-13**(审美 judge,2 页):判定结果、严重度与色差阈值数值等多处同时用红色强调，同一强调色承担太多重点，单处的强调力被稀释，读者分不出哪一处才是最该先看的结论。
  - 赢的做法:红色只留给判定结果（不达标、严重度高），阈值和色差数值改用中性色加粗，让红色在全页只有一个含义。
  - 证据:c1:混淆色表格里红色同时用于阈值数字与「不达标/高」判定，强调点过多导致重点分散；建议仅判定结果用红色，阈值数字改用中性色加粗。;c4:红色在「不达标」「严重度 高」「ΔE<12」三处同时使用，同一强调色承担三处强调，单处的强调力被稀释。

## 已解决

- **P-01**(审美 judge):核心指标一节的四个同级指标被排成一行三项、第二行一项，右侧留下大片空白，读者看不出这四个数字属于同一组。
- **P-04**(审美 judge):核心指标一节的几个指标数字完全等权，结论性的总括数字没有比其余指标更突出，读者一眼看不出该先读哪个、抓不到主结论；指标之间间距偏大，也削弱了它们同属一组的关联感。
