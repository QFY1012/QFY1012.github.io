# 问题清单 · 色觉无障碍分析

Maintainer 从训练样本的检测结果归纳,每步更新(最近一次:cvd-c10-k3-k4-k6,审美 judge)。Reviser 读「布局问题」,组件 Agent 读「组件不够」。改了什么、成没成功在修改记录 changelog.md(修改记录员写)。

## 组件不够

- **P-06**(审美 judge,3 页):ProgressList 的条比页面其它细线粗，使「按色盲类型」一栏的计数条成为屏内视觉重量最大的一块，与全页细线风格不一致。
  - 赢的做法:小条形图组与相邻表格共用一条对齐线，并给出刻度或数值基准；条用与页面细线一致的细条、浅色条，不与正文争夺视觉重量。
  - 证据:c1:系列色右列「按色盲类型」条形图的黑色线条明显粗于全页 1px 的表格分隔线，让这个次要模块的视觉重量偏重。;c3:受影响问题数的黑色横条是屏内视觉重量最大的一块。;c4:问题分布条形图只占内容列左侧约三分之一，右侧三分之二空着，右下出现一大块空白。
- **P-12**(审美 judge,2 页):FigureCompare 的每格图高固定、图注又各占一行，使截图比例偏长的报告里四张对照图仍被拉成上下两屏，后一屏只剩两张图与两个图注，读者无法在一屏内完成对照。
  - 赢的做法:四张对照图以能看清图内文字与色差的尺寸呈现，整组仍能在一屏内完成对照。
  - 证据:c2:色觉模拟第二屏只剩两张小图加两个图注，约占半屏，四张图被拉成两屏、无法作为一组对照阅读。;c3:色觉模拟区连续几屏每屏只有两张图，左侧标签列整条空白，四张图始终无法在一屏内以同一尺寸完成对照。
- **P-15**(审美 judge,3 页):ProgressList 的条是发丝细线或等长虚线、不带基线或刻度，条目标签还带多种颜色，使「按色觉类型的问题数」一栏既看不出数值差异、说不出这条线的作用，也与页面其它数字的呈现方式不一致。
  - 赢的做法:计数条与相邻表格共用对齐线，条上给出基线或刻度，数值差异一眼可辨，并与页面其它数字用同一套呈现。
  - 证据:c3:受影响问题数的三条横条长度完全相同，不编码任何数值差异，像说不出作用的装饰，右端也不与上方明细表共列线。;c3:同一计数在别处用表格数字表达，同类计数用了两种形式，与右侧数字不是同一套组件。;c1:「按色盲类型」标签与数字之间是一条灰色虚线引导线，与页面其它数字不是同一套组件。
- **P-21**(审美 judge,2 页):Group 的子块标题与节标题同为 20px，使「下一步」等节里的「颜色调整」「按问题处理」这类子块标题与节标题分不出层级，读者看不出这一节分成几块。
  - 赢的做法:子块标题在字号或间距上与节标题、正文拉开一级，使每块内容一眼可见。
  - 证据:c1:「下一步」下「颜色调整」「按问题处理」两个子块标题，加上「图表系列色」「按色盲类型」这类加粗标题，页面上出现四个差别很小的加粗级别，h2 与 h3 对比不足。;c1:两个子块标题的字号/字重层级不一致，与其他加粗标题难以区分。;c2:子块标题与正文、与区块标签的尺寸几乎相同，只靠字重区分，子块层级一眼看不出来。

## 布局问题

- **P-02**(审美 judge,1 页):颜色混淆一节的柱状图用多种高饱和色区分系列，填色面积最大的一根柱子承载的却是次要数据，抢走全页注意力，也和其余部分克制的灰加单一强调色配色冲突。
  - 赢的做法:同一组数据改用中性灰阶或低饱和呈现、只留一个强调色，红色只留给判定结果，全页视觉重量回到最重要的内容上。
  - 证据:c3:颜色混淆区的柱状图用橙、青、黄、深蓝四种高饱和色，是全页视觉重量最大的一块，却只是次要的说明数据，与全页黑灰细线的克制风格冲突。;c3:该图 accent 超过两种且饱和度不一致，抢走了结论与问题清单的焦点。
- **P-03**(审美 judge,2 页):同一节里把多种内容模块排在同一屏、模块间距小于节内分组间距，读者会把它们混成一块、分不清这一节里有几种内容。
  - 赢的做法:每块内容分到各自分组、组间距按节级处理，或把块标题层级做重，使分界一眼可见。
  - 证据:c3:颜色混淆一节把柱状图（含图例）、明细表、受影响问题数条形列表三块挤在同一屏，柱状图与明细表之间间距不足两个正文行高，分组被削弱。;c1:色觉模拟图尾部、核心指标四个数字、系列色表头挤在同一屏，一屏内出现图表、KPI、表格三种模块，间距只有约两个正文行高。
- **P-05**(审美 judge,3 页):「色觉模拟」一节的四张对照图与标签排布不成规整一组：标签与所属图片的间距过大、与图左边缘不对齐，留白不成矩形，读者无法把几张图当成同一组对照来读。
  - 赢的做法:四张对照图等宽排成规整一组，标签紧贴所属图片、与图左边缘对齐，留白成矩形，并与下方表格、图表共用同一条栏线。
  - 证据:c2:色觉模拟的四个图注与上方图、下方图的间距几乎相等，归属不清，这一处分组失效。;c1:2×2 图组第一行图注在图上方、第二行图注在图下方，两行的对齐线与基线不齐。;c4:2×2 缩略图因内部表格行数不同而高度不齐，同排两张图的底部图注不在同一基线上。
- **P-11**(审美 judge,4 页):内容很少的节（结论、背景信息等）单独占一屏、页头与结论之间也留出近半屏空白，一屏里只有一两行内容、大半留白，读者会觉得报告没有写完。
  - 赢的做法:内容很少的节与前一个节合并或就近成组，或压缩上下留白收尾，把结论上移、收紧标题区高度，使每屏都有两三种内容、模块间距仍是节内分组间距的两倍以上。
  - 证据:c2:色觉模拟后一屏只剩两张小图加两个图注，约占半屏，其余大半是空白。;c4:页尾「背景信息」下方留白稍多，若干屏下半部留白较多，未收住。;c2:核心指标与色觉模拟之间的节间距接近一整屏，留白过多，与相邻区块的间距不成比例。
- **P-13**(审美 judge,3 页):判定结果、严重度与色差阈值数值等多处同时用红色强调，同一强调色承担太多重点，单处的强调力被稀释，读者分不出哪一处才是最该先看的结论。
  - 赢的做法:红色只留给判定结果（不达标、严重度高），阈值和色差数值改用中性色加粗，让红色在全页只有一个含义。
  - 证据:c1:不达标、严重度高、低值数字都标红，每一处强调的力度被稀释。;c2:问题清单「影响」列整列用红色，而其它表格只在「不达标」一处用红，红色强调被稀释，真正的不达标反而不突出。;c4:同一红色出现在不达标、严重度、低于阈值的 ΔE 等多处，焦点被摊薄。
- **P-14**(审美 judge,3 页):「下一步/建议」一类的条目排成固定列数的网格时，条目数不是列数的倍数、或条目文案换行，末行只剩一两项或行高不齐，右下留下 L 形或锯齿状空白，读者会觉得这一块没收住。
  - 赢的做法:条目数与列数匹配（或改用单列、两列、等宽 2×3 排布），文案压到一行，末行不留孤立项和 L 形空白。
  - 证据:c4:「下一步」用 3 列网格只放 5 项，第二行只剩两项，右下空出一格形成 L 形留白。;c3:「下一步」01–03 横排三列、04 换行落到第一列下方，右侧空出大片 L 形空白。;c1:整改建议的 01–06 三列网格第 6 项文案换行成两行，该行底部高低不齐、留出锯齿状空白。
- **P-17**(审美 judge,1 页):核心指标一节的四个同级指标里只有部分带红色注释、结论句又另起一层加粗大字，同类内容的强调方式不一致，读者分不清哪些信息同等重要。
  - 赢的做法:四个同级指标共用同一套数字与说明样式，不单独给部分指标加红色注释；结论句与其余正文保持同一套样式。
  - 证据:c2:同一组四个核心指标中只有「对比度不达标」「色盲难以区分」两项下面多了红色补充行，另两项没有，同类内容内部结构不一致。;c2:同一层级的四条 KPI 说明里只有「低于 4.5:1」「绿色盲下 ΔE 9.0」两行用红色，另两行是灰色，同级内容出现两种颜色。
- **P-19**(审美 judge,3 页):表格、键值行与计数列表的数字右边缘落在不同的线上，右侧留白不成矩形、出现 L 形或锯齿状空白，读者看不出这些数字属于同一套列。
  - 赢的做法:各表格、数值列表与键值行共用同一组栏线，数值列右边缘对齐，留白都是规整矩形。
  - 证据:c1:核心指标数字与表格左边缘相差约 20px，系列色右列图表下方的留白不成矩形，数值列仍脱线。;c3:受影响问题数列表的长条右端与数字之间留白略松，与相邻表格不共列线。;c2:问题分布与明细区块内多个表格或数值列的右边缘不共线，缺少统一的列对齐线。
- **P-20**(审美 judge,2 页):结论区里判定句、结论句与补充说明用几乎相同的字号和字重，读者分不清哪一句是结论、哪一句是补充。
  - 赢的做法:结论句用结论字号单独成句，补充说明退回正文样式，两层一眼可分。
  - 证据:c4:结论区的「判定:不友好」独立成行，但字号与正文接近、又是常规黑色，与下方正文的层级对比不足，读者不易一眼看出这是结论判定。;c2:结论导语与区块标签、正文与注释的尺寸几乎相同，层级难分，分不出哪一层是结论、哪一层是补充说明。
- **P-22**(审美 judge,1 页):色板一节里计数条图与相邻色值表并排时高度差大，条图下方空出不成矩形的留白，读者看不出这两块属于同一行。
  - 赢的做法:并排两块的高度与行节奏匹配，或把条目少的块改为通栏、并入相邻表格，不留不成矩形的空白。
  - 证据:c1:「系列色」区块右列「按色盲类型」条形图只有三条数据，下方留出大片空白，与左侧 8 行表格的高度不匹配，右侧留白不成矩形。;c1:「系列色」一屏三栏宽度不均，条图只占上方一小块，下方空着。

## 已解决

- **P-01**(审美 judge):核心指标一节的四个同级指标被排成一行三项、第二行一项，右侧留下大片空白，读者看不出这四个数字属于同一组。
- **P-04**(审美 judge):核心指标一节的几个指标数字完全等权，结论性的总括数字没有比其余指标更突出，读者一眼看不出该先读哪个、抓不到主结论；指标之间间距偏大，也削弱了它们同属一组的关联感。
- **P-07**(审美 judge):核心指标一行的数字层级没有拉开：总结性指标与其余指标同字号同字重，只能靠位置区分重要程度，数字与单位的字号、基线关系也不统一，读者一眼抓不到主结论、单位也难读。
- **P-08**(审美 judge):「色觉模拟」一节把说明文字、多张对照截图和底部图注挤在同一屏内，模块间距小于节间距，是全页最挤的一屏，读者看不出哪几块属于同一组对照。
- **P-09**(审美 judge):DataTable 的 caption 固定居中，使各表格下方的口径注释落不到表格左右边缘上，表格右侧留出一块不规整的空白。
- **P-10**(审美 judge):FigureStrip 的滚动条一直显示，使色觉模拟的截图组下方多出一条贯通整栏的灰色横条，读者会把它当成多余装饰或分隔线。
- **P-16**(审美 judge):DataTable 的数值条颜色过淡且不带阈值参考线，使「对比度明细」的对比度一列无法从条长判断是否达标。
- **P-18**(审美 judge):核心指标一行的几个数字之间横向间距过大、接近节与节之间的间距，四个数字读起来不像一组，缺少比节更紧的绑定。
