# 输出指南 · 色觉无障碍分析 c4(候选,基于 g0)

这份指南只管「色觉无障碍分析」这个 Skill 的输出:它的数据怎么用组件库呈现、页面怎么组装。通用做法在公共规范 design.md 里,这里不重复。和公共规范 B、C 部分冲突时,以本指南为准;A 部分(基础)不能改。

## 规则

- **G1 分类型的问题编号对应**: `byType` 单独成一节(节名「分类型」,排在 `issues` 的问题清单一节的正前方,不放进 `palette`、`confusions`、`contrast` 所在的那一节);节 `description` 写统计口径「按 issues 里每条问题的 affects 统计,一条问题计入它影响的每个类型,所以各类型条数之和大于问题总数」。这一节只用一张 `DataTable`,行按 `byType` 数组顺序,三列:类型 `type`(span 2)、问题数 `issues`(span 2,`align: "right"`)、对应问题(span 5,取 `issues` 里 `affects` 数组包含该类型的条目,按 `id` 升序用「、」相连,如「P1、P3」;一条都没有时写「无」),匹配只按 `affects` 数组的包含关系、不做文字比对。不用 `BarChart` 或 `ProgressList` 显示 `byType`。问题清单里每条问题的标题前写出它的 `id`(如「P1」),与「分类型」一节共用同一套编号;`affects` 为空的问题照常列在问题清单里,只是不计入任何类型。
