# 输出指南 · 交互流程挖掘 c2(候选,基于 g0)

这份指南只管「交互流程挖掘」这个 Skill 的输出:它的数据怎么用组件库呈现、页面怎么组装。通用做法在公共规范 design.md 里,这里不重复。和公共规范 B、C 部分冲突时,以本指南为准;A 部分(基础)不能改。

## 规则

- **G1 链路明细**:明细一节里按 `chains` 一款产品一组,`Group` 的 `title` 写 `${product} · ${version}`;组内把该产品 `steps` 按 `no` 升序切成若干行,每行最多 4 步、放一个 `FigureStrip`(行数 = `ceil(steps.length / 4)`,末行不足 4 步按实际数量排),行内每个 `Figure` 依次放 `FigureImage`(`src` 用 `step.image`,`alt` 写 `${product} 第 ${no} 步:${screen}`)、`FigureLabel`(写「第 ${no} 步 · ${screen}」)、`FigureText`(写 `${content} · ${action}`)。`steps` 里每一步都要渲染出一个 `Figure`,不省略、不折成两行裁掉,也不靠横向滚动才能看全;产品数、步骤数不同时做法不变,产品依次上下排开,明细里 `FigureImage` 的总张数等于核心指标里「分析截图」的数值。
