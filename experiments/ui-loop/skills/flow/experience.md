# 问题清单 · 交互流程挖掘

Maintainer 从训练样本的检测结果归纳,每步更新(最近一次:flow-c10-k3-k4-k6-k7,审美 judge)。Reviser 读「布局问题」,组件 Agent 读「组件不够」。改了什么、成没成功在修改记录 changelog.md(修改记录员写)。

## 组件不够

- **P-15**(审美 judge,1 页):DataTable 的 bar 条与表格行线同色同粗，使产品对比表的步骤数列分不出数量差别。
  - 证据:f2:产品对比表「步骤数」列的细横线与表格行线同色同粗，5 与 4 的长度差几乎读不出来，像误加的分隔线(两种顺序都提到);f2:横线段与紧邻的数字重复编码同一信息，两段线右端还不齐
- **P-21**(审美 judge,1 页):DataTable 的 levels 除最高一级外没有可辨的强度差别，使问题明细表的严重度列只有「高」一级读得出来，中、低两级与正文没有视觉区别。
  - 证据:f2:问题表的「严重度」列只有「高」标红，「中」「低」与正文同色同重，三种状态只用颜色一个通道(两种顺序都提到);f2:红色「高」夹在表格中部，形成孤立的彩色强调，横向阅读被打断

## 布局问题

- **P-06**(审美 judge,2 页):报告里的数字强调层级不统一：同一批数据在不同区块被反复放大，大数字与正文字号之间又缺少中间层级，读者分不清哪一组数字才是全页重点。
  - 赢的做法:把大数字强调只留给核心指标一处，产品对比、流程对比这类同类数据收进正文级表格，全页只保留一组放大数字。
  - 证据:f1:「产品对比」的 9 步 / 7 步 / 10 步与「核心指标」用同一档大数字，「7 步」还在两处重复出现，主指标被稀释(两种顺序都提到);f3:「核心指标」四个数字与单位、正文的比例失衡，与正文之间缺少中间层级，读者分不出重点(两种顺序都提到)
- **P-08**(审美 judge,1 页):步骤备注这类条目少的分组排不满：条目分两列排后末行只占左列，右下方留下大块不成矩形的空白，这一节显得没收口。
  - 赢的做法:把条目少的分组改成通栏表格或单列排布，区块底边成矩形、不留半屏空白。
  - 证据:f3:步骤备注 01–05 分左右两列排成 3+2，右下角留下 L 形空白，分组也看不出来(两种顺序都提到);f3:五条短备注独占一整节，条目间距偏大，这一节显得没收口
- **P-12**(审美 judge,1 页):同一份报告里同类内容用了不同的组件形式：同为逐条记录，有的用编号列表、有的用表格，列表有的带分隔线有的没有，读者分不清条目边界，也不易判断哪些内容属于同一类。
  - 赢的做法:同类清单统一为「编号 + 加粗标题 + 灰色说明 + 分隔线」，同为横向对比的结构化数据统一用同款表格。
  - 证据:f1:「共性规律」与「下一步」同为编号条目列表却用了两套编号样式，层级感被削弱(两种顺序都提到);f1:两个编号列表结构相同，一个条目之间带分隔线、一个完全不带，同类组件样式不统一
- **P-14**(审美 judge,1 页):报告里各区块的内容起始位置不在同一条栏线上：表格的左缩进、列表的编号列和数字列、同一区块里上下两块各自的列网格各自为政，全页出现多条互不对齐的竖线，读者会觉得每一节都没有对齐。
  - 赢的做法:所有区块左对齐到同一条栏线，表格列与截图各列都落在共同列线上，模块之间留白均为规整矩形。
  - 证据:f3:「核心指标」四个数字与下方「产品对比」表格的列线不共线，两行大数字用了两套栏距(两种顺序都提到);f3:「步骤备注」列表与下方「问题」表格的栏线不在同一条对齐线上(两种顺序都提到)
- **P-22**(审美 judge,1 页):步骤备注按产品分组后，组标题与条目的层级差别太小，分组感和层级区分不足，读者仍分不出哪些条目属于同一产品。
  - 证据:f1:「步骤备注」整节的组标题与条目层级过于接近，只靠灰色小字和细灰线区分，分组感弱(两种顺序都提到);f1:组标题与条目、条目与条目之间的间距没有拉开档次，看不出分组节奏

## 已解决

- **P-01**(审美 judge):核心指标一节把数字按三列排，余下的数字单独折到第二行，右侧留出大片不成矩形的空白，几个指标不在同一视觉组里，读者会觉得这一节没排满、节奏被拉断。
- **P-02**(审美 judge):链路明细里各产品一组的截图说明文字长短、行数不一，有的还被右边界截断，各组说明底部与截图行下缘参差不齐，读者看不出哪些步骤属于同一组。
- **P-03**(审美 judge):DataTable 的 caption 注释固定居中，使表格下方要与表格左边缘对齐的口径说明脱离表格左对齐线，像一条游离在表格之外的尾巴。
- **P-04**(审美 judge):链路明细里截图、说明与下一组之间的纵向间距不统一，说明紧贴截图、组与组之间又隔得太近，分组层级看不出来，读者分不清哪些内容属于同一组。
- **P-05**(审美 judge):页面开头(标题与背景信息)和结尾(下一步)各有一屏只放两三行内容，其余大片留白，单屏信息密度过低，读者会觉得节奏松散。
- **P-07**(审美 judge):每步备注被抽成独立的表或块放在截图组之后，与对应的截图之间没有编号或指向关联、又不在同一屏，读者要跨区块回看才能把备注和截图对上，内容还与截图说明重复。
- **P-09**(审美 judge):区块之间的纵向间距不统一：标题与紧随其后的第一块内容之间常常接近半屏或三分之一屏，同一页里有的区块又挨得过近，全页垂直韵律忽紧忽松。
- **P-10**(审美 judge):链路明细要在不同产品的截图组之间做出分组，但组件库缺少线宽与表格行线一致的分组标记组件，所以无法展示。
- **P-11**(审美 judge):报告里的表格在页边界被切开：表头不重复、注释单独落到下一屏，读者要跨屏拼接才能把列首和注释对上，也看不出注释属于哪张表。
- **P-13**(审美 judge):「下一步」多条建议并排成几栏时各栏文字行数不同、末栏偏短，栏底参差不齐，下方留出 L 形空白，这一节显得没收口。
- **P-16**(审美 judge):DataTable 的 tone 只改字色、不提供字重或标记，使问题明细表的严重度一列只有颜色一个通道，标红的值与普通文字没有粗细差别，色弱读者和灰度打印读不出轻重。
- **P-17**(审美 judge):报告里同一信息在相邻位置重复出现：建议条目的自带编号与列表序号并列，备注的步骤列与上方截图说明重复，表格里同一个产品名逐行重复，读者要读两遍同样的内容，也挤占了正文宽度。
- **P-18**(审美 judge):步骤备注、发现这类逐条清单没有分出层级：同一产品的条目和其它产品一律等距排在一起，条目间距又和区块间距接近或过疏，读者看不出分组、也读不出节奏。
- **P-19**(审美 judge):报告里的表格列宽分配不合理：窄列里的内容被挤成多行、宽列之间留出大片空带，表格内部留白不成矩形，相邻表格的列线也互不重合。
- **P-20**(审美 judge):并列的两张表格(产品对比与问题)用同一套表头与行线样式、没有分组线，读者分不出哪张是中性对比数据、哪张是问题清单。
