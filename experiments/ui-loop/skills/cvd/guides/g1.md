# 输出指南 · 色觉无障碍分析 g1

这份指南只管「色觉无障碍分析」这个 Skill 的输出:它的数据怎么用组件库呈现、页面怎么组装。通用做法在公共规范 design.md 里,这里不重复。和公共规范 B、C 部分冲突时,以本指南为准;A 部分(基础)不能改。

## 规则

- **G1 问题清单带建议列、与下一步同号**:`issues` 在「明细」一节用一张 `DataTable`(同一节还有别的明细表时排在最后),一行一条问题,列依次为编号 `id`、问题 `title`、类型 `type`、位置 `location`、影响 `affects`、严重度 `severity`、建议 `suggestion`,依次取 `span` 1、2、1、1、1、1、2;`affects` 用顿号连接色觉类型,空数组留空;`severity` 为「高」的单元格用该列 `tone` 标红;行按 `severity` 高→中→低排,同档按 `id` 排。「下一步」一节的 `List` 每条 `title` 以对应问题编号开头(如「P1 折线图系列 2、3 红绿色盲分不清」),与问题清单的编号列一一对应;`severity` 为「高」的每条都必须在「下一步」出现,不足 3 条时按严重度往下补足,多于 3 条不删;`issues` 为空时这两处都跳过。
